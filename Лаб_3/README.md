# Среднее значение чисел


## Переменные и действия над ними

### Типы переменных
По умолчанию, при вводе значения для переменной в кавычках "число/буква" используется тип "str", то есть строка, однако для моей задачи требуется тип float, то есть числа с десятичной частью.
Пример переменной для моей работы:
`x = float(input("Введите значение 1-го числа: "))`
Важно добавить, что текст в кавычках выводится в консоль как подсказка для человека и особой роли в коде не играет.

### Какая формула используется для определения средних значений 3-х чисел
Так как используется всего 3 переменной типа float, то формула будет выглядеть примерно следующим образом:
`result = round((x + y + z) / 3, 2)`
#### Что означает "round" в этой строке кода?
round - это встроенный инструмент для округления чила, в моём случае число округляется до 2-х знаков после запятой, так как стоит round("xxxxxx, 2")
Число 2 - указывает как раз на количество знаков после запятой.
**Запятая** после самого выражения - **обязательна**!

### Вывод значений
Значения выводятся при помощи команды `print("текст")`, однако касательно вывода переменных есть небольшой ньюанс...
При выводе с переменной необходимо употреблять "f", то есть код следующего вида:
`print(f"text {variable}")`

## Ответы на контрольные вопросы

**Что такое интерпретатор Python и какую роль он выполняет?**  
Интерпретатор Python — программа, которая читает и выполняет код Python построчно. Он преобразует инструкции в действия, понятные компьютеру, и управляет выполнением программы.

**Как проверить установку Python и запустить скрипт из консоли?**   
Проверить установку можно командой python --version (или python3 --version). Запустить скрипт — командой python имя_файла.py (или python3 имя_файла.py) в консоли из папки со скриптом.

**Что такое переменная и какие правила используются при её именовании?**    
Переменная — именованное хранилище для данных. Правила именования: начинать с буквы или подчёркивания, использовать буквы, цифры и подчёркивания, не применять зарезервированные слова, учитывать регистр (name и Name — разные имена).

**Какие основные типы данных используются в простых программах?**   
Основные типы: целые числа (int), числа с плавающей точкой (float), строки (str), булевы значения (bool), списки (list), словари (dict), кортежи (tuple).

**Как выполняется ввод данных от пользователя с помощью input()?**  
Функция input() считывает введённый пользователем текст как строку и возвращает её в программу.

**Почему часто необходимо преобразовывать введённые строки в числа?**   
Потому что input() всегда возвращает строку, а для математических операций и сравнений нужны числовые типы (int, float).

**Какие арифметические операции используются в Python и каков их приоритет?**   
Операции: сложение, вычитание, умножение, деление, целочисленное деление, остаток от деления, возведение в степень. Приоритет: сначала возведение в степень, затем умножение/деление/остаток/целочисленное деление, потом сложение и вычитание; скобки меняют порядок.

**Как выполняется вывод результатов с помощью форматированных строк?**  
Форматированный вывод делают через f‑строки, метод .format() или оператор %; они позволяют вставлять значения переменных в текст.

**Для чего используются комментарии в коде?**   
Комментарии поясняют логику кода для людей, не влияют на выполнение программы, помогают в поддержке и отладке.

**Как оформляется последовательный алгоритм обработки входных данных?** 
Алгоритм оформляют как последовательность шагов: ввод данных, их проверка и преобразование, вычисления, вывод результата; в коде это отражается линейной структурой инструкций.

**Как проверить программу на нескольких наборах входных данных?**   
Проверку делают, запуская программу с разными входными значениями, включая типичные, граничные и некорректные случаи; также используют отдельные тесты или циклы с набором данных.

**Какие типичные ошибки возникают при вводе, выводе и преобразовании типов?**   
Типичные ошибки: неверный тип данных при преобразовании (например, текст вместо числа), опечатки в именах переменных, путаница между строкой и числом, ошибки форматирования при выводе, ввод пустых или неожиданных значений.
